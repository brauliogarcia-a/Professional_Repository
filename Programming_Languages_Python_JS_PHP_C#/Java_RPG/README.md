# Overview

Description:
The program presents a short RPG story based on the witcher world. is a story that I created. Is an RPG because it contains certain elements, like chose a personage, attributes, the user can read a story that change based on decisions that user will take during the game. The game also allow the user to fight or run from different fights. The game contains three monster types. Based on the decisions, the personage will live or die.

Purpose: To create a short RPG text based in Java. Show the ability to use the basic concepts learned during the semester (variables, expressions, conditions, loops, functions, classes)
