# Overview

Description:
The project consist on creating a python script that will connect to a database in the cloud (AWS) and will perform some CRUD operations. The changes in the DB will be shown in MySQL Workbench.

Purpose: This python script is going to create a database, create some tables based on two CSV files, and run some queries on a database hosted in the cloud. 

[Software Demo Video](https://youtu.be/HrdJaU-uSnQ)

# Relational Database

The database motor that I used for this project is MySQL but on AWS.

There are two tables, the student table and the school table. both of them are related using the school id column.
