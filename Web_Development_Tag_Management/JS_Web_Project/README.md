# Overview

Description:
This project use HTML, CSS, and JavaScript code to generate a simple daily planner or a to do list. It allows the user to add a task, mark it as complete or incomplete, or delete it. it also let the user know how many tasks are incomplete.

Purpose: Generate a daily planner that use web based technologies and allows the user to track their daily activities. The program will store the information that the user don't lose its activity.
